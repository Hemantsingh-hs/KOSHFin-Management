# KOSH – Finance & Property Management

KOSH is a web-based platform designed to help users **manage their finances and property-related activities in one place**.

It combines personal finance management with **PG, room, hostel, mess, tenant, and rent management** features.

## 🚀 Project Overview

KOSH aims to provide a simple and convenient platform where users can:

- 💰 Track income and expenses
- 📊 Monitor savings and financial goals
- 🏠 Manage PGs, rooms, and properties
- 👥 Manage tenants and occupancy
- 💳 Track rent and payments
- 🔔 Receive rent/payment reminders
- 🍽️ Manage mess-related information
- 📍 Discover PGs, rooms, messes, and hostels near a location
- 📈 View financial and property-related reports
- 🤖 Get AI-powered financial insights

## 🎯 Objectives

The main objectives of KOSH are:

1. Provide a centralized platform for finance and property management.
2. Simplify tenant and room management for property owners.
3. Help users track income, expenses, rent, and savings.
4. Provide location-based property discovery.
5. Reduce manual work through automated reminders and notifications.
6. Provide useful reports and insights through a simple interface.
